# Video Logo Processor

Procesa videos con FFmpeg mediante GitHub Actions.

Configuración:
- Columna D: URL del video original.
- Columna E: URL del video procesado.
- Columna F: estado.
- Logo centrado horizontalmente en la parte inferior.
- Logo: 30% de la altura del video.
- Margen inferior: 2%.
- Audio original conservado.
- Procesamiento por lotes desde Apps Script.
- El resultado se publica temporalmente como un artifact de GitHub Actions.

El repositorio no contiene credenciales ni videos.
